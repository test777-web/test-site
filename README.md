# AutoGlob — сайт (v3)

Усі файли лежать пласко, без підпапок.

## Що є в цій збірці

1. **Реальний логотип** (`logo.png`) — твій файл з прозорим фоном (фон вирізаний автоматично), використаний і в шапці, і у футері.
2. **Шапка і футер завжди темні**, незалежно від обраної теми — це навмисно: тримає бренд-кольори стабільними і не ламає контраст білого тексту в лого. Світлою/темною перемикається тільки основний контент сторінки.
3. **Перемикач теми** — кругла кнопка з монохромною SVG-іконкою (сонце/місяць), без кольорових emoji. Вибір теми зберігається в браузері (localStorage).
4. **Хедер працює**: Newsletter і Sign in відкривають модалки (поки без реального бекенду), Search фільтрує статті вживу.
5. **Меню з 4 пунктів**: News, Reviews, Known Issues, Car as Investment — фільтрують сітку "Recent Articles" на місці, без переходу на іншу сторінку.
6. **Дублікатів немає**: "Featured" — один spotlight-блок (найсвіжіша новина), "Recent Articles" — три інші унікальні статті.
7. **Фото без агресивної обрізки**: стрічка новин тепер використовує м'яку обрізку 4:3 замість 1:1, яка раніше зрізала частину кузова в Polestar і Audi.
8. **`translate="no"`** на кожній сторінці — Chrome більше не пропонує автопереклад, який раніше конфліктував із JS.
9. **Кеш-бастинг**: `style.css?v=3` і `site.js?v=3` — щоб браузер і GitHub Pages підвантажували свіжі файли після кожного нового деплою, а не стару закешовану версію.

## Структура файлів

```
index.html                              — головна
article-gr86-review.html                — огляд Toyota GR86 (Reviews)
news-polestar-us-ban.html               — новина про Polestar (News)
audi-a8-discontinued-investment.html    — стаття про Audi A8 (Car as Investment)
bmw-n54-known-issues.html               — стаття про BMW N54 (Known Issues)
style.css                               — усі стилі, тема, брендові кольори
site.js                                 — тема, пошук, фільтр меню, модалки
logo.png                                — логотип AutoGlob (прозорий фон)
hero-*.jpg / card-*.jpg                 — фото для кожної статті
```

## Важливо: після кожного нового деплою онови сторінку без кешу

Якщо після заливання нової версії на GitHub Pages зміни не видно (наприклад тема знову "не працює"), спочатку зроби жорстке оновлення сторінки (в Chrome на телефоні: Меню → Оновити, або очисти кеш сайту), перш ніж вважати щось зламаним. Кеш-бастинг (`?v=3`) це вже сильно знижує ризик, але за потреби онови версію ще на одиницю (`?v=4` і т.д.) при наступних правках.

## Що ще не зроблено (на майбутнє)
