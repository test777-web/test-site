# AutoGlob — тестовий сайт

Каркас сайту на HTML/CSS, готовий для GitHub Pages. Заповнений однією пробною статтею з коректними Open Graph / Twitter Card тегами, решта — заповнювачі.

## Структура

Усі файли лежать пласко, без підпапок:

```
index.html                              — головна сторінка
article-gr86-review.html                — огляд Toyota GR86
news-polestar-us-ban.html               — новина про Polestar
audi-a8-discontinued-investment.html    — стаття про Audi A8
bmw-n54-known-issues.html               — стаття Known Issues про BMW N54
style.css                               — усі стилі
hero-*.jpg / card-*.jpg / featured-*.jpg / thumb-*.jpg  — реальні фото для кожної статті
logo.png                                — логотип AutoGlob
```

## Як розмістити на GitHub Pages

1. Створи новий репозиторій на GitHub (наприклад, `autoglob-site`).
2. Розпакуй цей ZIP і залий усі файли в корінь репозиторію (git add / commit / push, або через "Add file → Upload files" у веб-інтерфейсі GitHub).
3. У репозиторії: **Settings → Pages → Source** → вибери гілку `main` і папку `/root`.
4. Через 1–2 хвилини сайт буде доступний за адресою:
   `https://ТВІЙ-НІК.github.io/autoglob-site/`
5. Онови URL картинок і сторінки в мета-тегах статті (`og:image`, `og:url`, `twitter:image`) на цю реальну адресу — зараз там стоїть заглушка `REPLACE-WITH-YOUR-DOMAIN`.

## Що замінити перед реальним запуском

- SVG-заповнювачі в `/images` → реальні фото (JPG/PNG/WebP), 1200×630 для hero/OG-картинки, 4:3 та 9:14 для карток.
- Логотип (`images/logo.svg`) → фінальний лого AutoGlob.
- Плейсхолдер-картки на головній → реальні статті.
- URL у мета-тегах статті → фінальна адреса сайту.

## Пробна стаття — переклад (для тебе, не для публікації)

**Заголовок:** Я проїхав на 2026 Toyota GR86 Yuzu Edition: чесний огляд

Toyota не переробила GR86 заради версії Yuzu Edition — просто додала лімітований жовтий колір кузова "юдзу", чорні 18-дюймові диски та сидіння зі спеціальною строчкою. На перший погляд це схоже на маркетинговий хід. Насправді це нагадування, про яке автоіндустрія часто забуває: іноді машина вже була достатньо гарною.

GR86 ніколи не була про цифри. Її 2.4-літровий опозитний чотирициліндровий двигун видає скромні 228 к.с., розгін до 100 км/год займає неквапливі 6.1 секунди. Навіть базова Camry обжене її без зусиль. Але кінська сила ніколи не була суттю цього авто, і Yuzu Edition цього не приховує.

**Іронічний поворот:** поки решта виробників додає підписки на софт і екрани, стратегія Toyota для "спецверсії" — прибрати зайве. Немає оновленої мультимедіа. Немає додаткового пакета асистентів водія. Лише добре налаштоване шасі, 6-ступенева механіка та блокування диференціала, які роблять те, що завжди робили — чесно передають, що коять задні колеса, без "перекладу" через комп'ютер.

*Цитата:* "Це рідкісний автомобіль, який відчувається дорожчим у керуванні, ніж коштує у салоні."

На вузькій заміській дорозі GR86 обертається з чесністю, яка зникла з більшості цього сегменту. Заднє гальмування в поворот — і задня вісь передбачувано зісковзує, легко коригується невеликим рухом керма й газом. Ніщо не відчувається штучним чи "підстрахованим" від власних помилок водія.

**У щоденному житті:** салон тісний, багажник малий, підвіска жорстка — на швидкісній трасі відчуєш кожен стик асфальту. Це не критично, якщо машина здебільшого для вихідних заради самого водіння. Але важливо, якщо це єдиний автомобіль і щоденний маршрут з ямами та пасажирами.

Витрата палива — близько 25 миль/галон (US) у змішаному циклі, нічого видатного, але й не в цьому суть. Репутація надійності Toyota зберігається, а платформа GR86 вже достатньо доросла, щоб основні "дитячі хвороби" експлуатації були добре задокументовані.

**Висновок:** Yuzu Edition не змінює суть GR86 — просто перефарбовує вже чудове маленьке спорткупе і просить помірну доплату за право виділятися на зустрічі Cars & Coffee. Якщо формула GR86 (легкість і зворотний зв'язок замість грубої потужності) вже подобалась — це гарний привід узяти саме цей колір. Якщо не подобалась — жовта фарба нічого не змінить, і не мусить.
