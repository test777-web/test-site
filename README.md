# AutoGlob — сайт (v4)

Усі файли лежать пласко, без підпапок.

## Що нового в v4

1. **Виправлено перемикач теми (реальна причина знайдена й підтверджена тестами).** Якщо браузер блокує `localStorage` (буває через налаштування приватності на мобільних), весь скрипт раніше падав з помилкою ще до прив'язки кліку до кнопки — вона виглядала "живою" (CSS-ефект наведення), але не працювала. Тепер усі звернення до `localStorage` обгорнуті в try/catch, тема перемикається завжди, незалежно від налаштувань браузера.
2. **Прибрано блок трьох фото під шапкою** ("Polestar is being pushed out...", "Audi's flagship...", "BMW's favorite tuner engine") — він дублював контент, який уже є нижче (Spotlight + Recent Articles), і не був клікабельним. Поверне сенс, коли на сайті буде значно більше статей.
3. Кеш-бастинг піднято до `?v=4` — після заливання на GitHub переконайся, що бачиш саме цю версію (можна перевірити в DevTools → Network → site.js).

## Що було раніше (v1-v3)

- Реальний логотип (`logo.png`), шапка і футер завжди темні незалежно від теми
- 4 пункти меню з фільтрацією статей на місці (без переходу на іншу сторінку)
- Прибрано дублікати статей між Featured і Recent Articles
- Виправлена обрізка фото (м'яка 4:3 замість агресивної 1:1)
- `translate="no"` — Chrome більше не пропонує автопереклад

## Важливо: після кожного нового деплою онови сторінку без кешу

Якщо після заливання нової версії на GitHub Pages зміни не видно (наприклад тема знову "не працює"), спочатку зроби жорстке оновлення сторінки (в Chrome на телефоні: Меню → Оновити, або очисти кеш сайту), перш ніж вважати щось зламаним. Кеш-бастинг (`?v=3`) це вже сильно знижує ризик, але за потреби онови версію ще на одиницю (`?v=4` і т.д.) при наступних правках.
