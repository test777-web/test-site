# AutoGlob — сайт (v2)

Усі файли лежать пласко, без підпапок.

## Що нового в цій збірці

1. **Хедер працює.** Newsletter і Sign in відкривають модальні вікна (поки без реального бекенду — форма підписки нічого нікуди не відправляє, це заготовка під майбутній email-сервіс типу Mailchimp чи ConvertKit). Search розкриває поле пошуку і фільтрує картки статей на головній вживу, поки друкуєш.
2. **Меню скорочено до 4 пунктів:** News, Reviews, Known Issues, Car as Investment. Кожен пункт фільтрує сітку "Recent Articles" по категорії прямо на місці (JS, без переходу на нову сторінку).
3. **Дублікати прибрано.** Раніше одна й та сама стаття (GR86, BMW N54, Audi A8) показувалась і у "Featured", і в "Recent Articles". Тепер "Featured" — це один великий spotlight-блок (найсвіжіша новина, зараз це Polestar), а "Recent Articles" показує три інші статті без повторів.
4. **Hover-ефекти.** Заголовки статей (на картках, у spotlight, у стрічці новин) підсвічуються бірюзовим кольором при наведенні курсора.
5. **Перемикач теми.** Кнопка "☀️ Light / 🌙 Dark" у верхній панелі. Вибір зберігається в браузері (localStorage), тому тема не скидається при переході між сторінками чи оновленні.
6. **Новий бренд за брендбуком:**
   - Назва одним словом: **AutoGlob** (Auto — основний колір тексту, Glob — бірюзовий), з червоним підкресленням
   - Кольори: фон `#081625`, акцент `#12D6D0`, другий акцент `#E53935`, текст `#F5F7FA`
   - Шрифт Montserrat (підключений через Google Fonts, підвантажується в браузері користувача)
   - Логотип поки текстовий (без кругової емблеми AG — її додамо окремим файлом, коли буде готовий SVG/PNG)

## Структура файлів

```
index.html                              — головна
article-gr86-review.html                — огляд Toyota GR86 (категорія Reviews)
news-polestar-us-ban.html               — новина про Polestar (категорія News)
audi-a8-discontinued-investment.html    — стаття про Audi A8 (категорія Car as Investment)
bmw-n54-known-issues.html               — стаття про BMW N54 (категорія Known Issues)
style.css                               — усі стилі, включно зі світлою/темною темою
site.js                                 — тема, пошук, фільтр меню, модалки
hero-*.jpg / card-*.jpg / featured-*.jpg / thumb-*.jpg  — фото для кожної статті
```

## Важливо: онови URL перед публікацією

У мета-тегах усіх 4 статей (`og:image`, `og:url`, `twitter:image`) зараз стоїть адреса:
```
https://test777-web.github.io/test-site/
```
Це моє припущення на основі скріна репозиторію, який ти показував раніше. Якщо назва репозиторію інша — заміни цей рядок на реальну адресу в усіх чотирьох HTML-файлах статей (по 3 місця в кожному файлі), інакше прев'ю в X/Facebook знову буде порожнім.
